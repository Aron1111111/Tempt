# 本次新增规则 / Новые правила упражнения

本文件定义本次练习新增的规则；昨日活动列表和报名API的行为保持原定义。
Здесь определены новые правила упражнения; исходные API списка встреч и записи сохраняют поведение.

## FR-DESC 活动描述 / Описание встречи

输入必须是字符串，先去除首尾空白，再按Unicode码点计数；长度10–1000含边界。None、空串和全空白返回DESCRIPTION_REQUIRED；非字符串返回INVALID_DESCRIPTION_TYPE；9字符为DESCRIPTION_TOO_SHORT，1001字符为DESCRIPTION_TOO_LONG。
Ввод — строка. Краевые пробелы удаляются, длина считается в кодовых точках Unicode: 10–1000 включительно. None, пустая и пробельная строка дают DESCRIPTION_REQUIRED; другой тип — INVALID_DESCRIPTION_TYPE; 9 символов — DESCRIPTION_TOO_SHORT, 1001 — DESCRIPTION_TOO_LONG.

成功返回规范化描述。OpenAPI的minLength/maxLength用于描述规范化后的值；空白预处理须由业务逻辑执行。未来HTTP适配层将校验错误映射到400与code，目前没有HTTP实现。
Успех возвращает нормализованное описание. minLength/maxLength описывают нормализованное значение, а удаление пробелов выполняет логика. Будущий HTTP-адаптер возвращает 400 и code; сейчас HTTP не реализован.

## FR-STATUS 活动状态 / Статусы встречи

组织者可执行draft → published/cancelled，published → completed/cancelled；completed和cancelled为终态。普通参与者无修改权限。重复设置同一状态不允许。
Организатор может выполнить draft → published/cancelled и published → completed/cancelled. completed и cancelled — конечные состояния. Участник менять статус не может. Переход в то же состояние запрещён.

非法状态：INVALID_STATUS；无权操作：ROLE_FORBIDDEN；非法转换：INVALID_STATUS_TRANSITION。未来HTTP适配分别映射400、403、409；认证缺失401、活动不存在404由未来适配层负责，纯逻辑模块不伪造认证或数据库检查。
Ошибки: INVALID_STATUS, ROLE_FORBIDDEN, INVALID_STATUS_TRANSITION. Будущий HTTP-адаптер сопоставляет их с 400, 403, 409; отсутствие аутентификации 401 и встречи 404 также проверяет адаптер. Модуль не имитирует аутентификацию или базу.
