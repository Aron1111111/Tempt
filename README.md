# 图书俱乐部代码审查实践 / Code Review Книжного клуба

继续昨日Aron1111111/docs中的图书俱乐部文档项目。本仓库将活动描述校验与活动状态流转作为两个独立PR练习。
Продолжение документационного проекта Aron1111111/docs. Проверка описания встречи и переходы статусов оформлены как два отдельных PR.

这是根据课堂任务自建的Python续作，不是老师提供的原始初始化脚本；原项目目前以文档和OpenAPI为主。
Это самостоятельно подготовленное продолжение на Python, а не исходный скрипт преподавателя. Исходный проект содержит документацию и OpenAPI.

## 分支与PR / Ветки и PR

| 分支 / Ветка | 内容 / Содержание |
| --- | --- |
| main | 项目基础、规则与原接口规范 / Основа, требования и исходный OpenAPI |
| feature/description-validator | 活动描述10–1000字符校验 / Описание встречи от 10 до 1000 символов |
| feature/status-transitions | 活动状态和角色规则 / Статусы встреч и права ролей |

两个功能分支分别从同一个main创建，分别向main发起PR；先保持未合并，供后续审查。
Обе ветки созданы от одной main и имеют отдельные PR в main. Слияние отложено до последующей проверки.

## 运行 / Запуск

安装Python 3.10或更新版本，在终端执行：
Нужен Python 3.10 или новее. Выполните в терминале:

```sh
git clone https://github.com/Aron1111111/Tempt.git
cd Tempt
python -B -m unittest discover -s tests -v
git switch feature/description-validator
python -B -m unittest discover -s tests -v
git switch feature/status-transitions
python -B -m unittest discover -s tests -v
```

不需要额外Python依赖；测试命令退出码0表示通过。两个功能尚未进入main，需切换对应分支查看代码。
Дополнительные зависимости Python не нужны. Код завершения 0 означает успех. Для просмотра функций переключитесь на нужную ветку.

新增功能是可测试的领域逻辑，不包含HTTP服务器、数据库、网页或真实邮件服务；OpenAPI是接口设计，不代表接口已运行。
Добавлена тестируемая предметная логика без HTTP-сервера, базы, веб-интерфейса и почты. OpenAPI описывает проект интерфейса, а не работающий сервис.
